# 文件、版本与可靠保存

这些是默认约定。用户指定的名称、位置、格式和编辑范围优先。本参考处理 MCP 操作与交付，不定义图的设计方法。

## 主题目录与四个同名文件

```text
项目文档/
├── 漏标示意图/
│   └── v1/
│       ├── 漏标示意图.drawio
│       ├── 漏标示意图.png
│       ├── 漏标示意图.svg
│       └── 漏标示意图.drawio.svg
└── ModelFramework/
    └── v1/
        ├── ModelFramework.drawio
        ├── ModelFramework.png
        ├── ModelFramework.svg
        └── ModelFramework.drawio.svg
```

- 主题可中可英，目录与文件主名一致，版本只写在 `vN` 目录中，不额外追加 `_v1`。
- “项目文档”是可替换示例，不是必须创建的字面目录。优先沿用用户位置和项目结构，遵守当前工作区的输出约束，不绑定某台机器的绝对路径。
- 普通图默认本地交付；只有用户指定其他平台、提供相应资源或已有明确平台任务上下文时，才使用该平台。
- 素材压缩副本、截图和诊断记录放在允许的工作目录，不混入正式四文件。原始素材保持不变。

| 文件 | 用途及操作要求 |
| --- | --- |
| `.drawio` | 继续编辑的源文件；多页完整保存不带页选择参数。 |
| `.png` | 渲染预览；通过 MCP 实际导出，默认背景遵从服务与任务要求。 |
| `.svg` | 普通矢量输出；不能把它当作必然包含可重新载入图源的文件。 |
| `.drawio.svg` | 含图源数据的可编辑 SVG；以 `format: "drawio.svg"` 或对应扩展名通过 MCP 导出，不能改名伪造。 |

创建、修改、保存及四格式导出均走 MCP。文件读取、格式检查和素材预处理可用现有工具，但不能使用桌面应用、转换器或脚本补导出图。

## 版本与旧命名

新主题从 `v1` 开始，已有主题默认更新当前确认的版本。任何修改本身都不自动触发升版；仅在用户明确要求新版本或另存 `vN` 时创建新目录。

未指定新编号时取最大现有数字编号加一，不补空缺，例如 `v1`、`v3` 后是 `v4`。编号与继承源分开：用户指定文件或已确认画布优先；来源有歧义才展示具体候选确认，不凭最大编号或时间戳覆盖。

旧文件如 `Model_paper_framework_v8.drawio` 继续原名保存；默认补齐或同步同主名 `.png`、`.svg`、`.drawio.svg`，不因此改名、迁移或升版。用户明确只要部分格式时按其要求。

用户明确另建新版本时，新目录中的新文件采用主题主名，旧版本文件不改动。例如从 `ModelFramework/v1/Model_paper_framework_v1.drawio` 继承，且最大版本为 `v3`，则新建 `ModelFramework/v4/ModelFramework.*` 四文件；用户另有主名要求时遵从其要求。

## 多页与选择参数

- 先 `list_pages`，建立页 ID、页名与输出路径的对应关系。编辑不选页可能使用第一页，图片导出不选页可能使用活动页，不能混淆。
- 完整 `.drawio` 保存全部页，不传页选择参数。单页四文件保持默认结构；已有多页按既定映射导出各请求页，不为新增第四格式自动重组目录。
- 首次交付已有多页图且没有既定图片映射时，在当前 `vN` 下按页主题建立同名子目录，例如 `总体结构/总体结构.png`、`.svg`、`.drawio.svg`；完整 `.drawio` 仍保存在主题根下。
- 页级 `.drawio.svg` 可能只嵌入所选页，反馈时说明页范围；它不替代完整 `.drawio`。需要完整多页可编辑 SVG 时，核对当前工具的无页选择行为与嵌入页数，不能默认为单页导出包含所有页。
- 页名重复、不可作文件名或与现有内容冲突时，确认无法推断的映射，不能让不同页覆盖同一文件。
- 用户只改一页时，保存完整源文件，更新该页相关 PNG、SVG、`.drawio.svg`。只有用户要求时才额外导出全部页或拆图，容量不足不构成自动拆页授权。

## 先保全当前画布

“保存最新修改”针对当前画布。先 `get_diagram`，不能先加载磁盘旧版。切换、恢复或重开前确认是否会替换未保存内容；目标与授权已明确时继续，不为每种格式重复确认。

当前会话若是另一幅有未保存修改的图，先取回当前状态并记录可用的会话标识及保存位置。读取到 XML 不等于已保存，新建会话也不等于旧修改已安全保留。核实旧会话与修改可恢复后，才在独立会话操作本次目标；不能安全切换、又没有已授权保存方案时，保留旧会话并一次确认处理方式。

`get_selection` 不可用时按画布、页、标签和位置定位，仍有多个候选才具体询问。不要把预览模式不支持选择读取，误诊为安装失败。

## 同步警告与导出期间的修改

`get_diagram` 或 `.drawio` 导出可能返回成功，同时提示浏览器未响应、内容可能遗漏最新手动修改。先读取并处理这种警告，不把“成功”解释为“最新”。遇警告时恢复预览连接并重新同步；如果目标文件已被该调用写入，说明落盘的是尚未确认最新性的状态，恢复后重导，不隐瞒它已写入。

服务的各次导出不共享一个公开快照锁。导出前读取当前状态，导出后再检查页、对象及相关内容，核对是否变化、是否仍有同步警告；折叠的图片引用也不证明完整二进制或导出文件一致。

对照内容时区分非内容状态：仅视口或缩放变化、XML 属性顺序与缩进变化，不应误判为图内容被编辑。页范围、对象文字、样式、坐标、尺寸、连接和素材变化仍需核对，不能为消除误报而一并忽略。

发现变化时，先重新取得稳定状态，再更新受影响的产物。无法排除变化时报告同步未确认，不将四个不同时间的输出称为一致；持续手动编辑导致无法稳定时，只需一次说明原因并请用户暂缓编辑。

## 导出结果与有限恢复

优先检查连接、目标页和容量。预览关闭或后台节流时恢复预览后重试一次；明确容量问题时，按 [图片预处理与容量控制](images-and-limits.md)先修正再重试一次。不要无变化地反复导出或借助其他导出器。

部分格式成功时保留成功文件并列出缺项；已有旧图片不能充当本次导出。可编辑 SVG 必须检查嵌入图源，必要时在安全会话用 `load_diagram` 回读并核对页和对象。重开前保存当前状态，不能为验证而覆盖未保存修改。

验收分别说明：工具是否响应、源文件是否写入、请求的四格式是否重新导出、页范围及内容是否核对、最终渲染是否实际查看。图片缺失、空白或资源未加载属于技术结果问题，应据实处理；不在此技能加入视觉风格评分或设计步骤。
